1. What Are Relations in Prisma?
In Prisma ORM, Relations define how two or more database models are connected.

Prisma supports three main relationship types:
1. One-to-One (1:1)
2. One-to-Many (1:N)
3. Many-to-Many (M:N)


2. One-to-One Relationship (1:1)
One record in a table is associated with only one record in another table.

Real-world example: One user has one profile.

Important Prisma Methods

// CREATE
await prisma.user.create({ data: { name: "Rahim", email: "rahim@gmail.com", password: "hashed" } });

// READ
await prisma.user.findMany();

// READ ONE
await prisma.user.findUnique({ where: { id: 1 } });

// UPDATE
await prisma.user.update({
  where: { id: 1 },
  data: { name: "Karim" }
});

// DELETE
await prisma.user.delete({ where: { id: 1 } });

19-9 – Advanced Prisma Queries: Summary

1. Important Concepts
Concept	Prisma Syntax	কাজ
Filtering	where	নির্দিষ্ট শর্তে data খোঁজা
Sorting	orderBy	Data সাজানো
Pagination	skip, take	Page অনুযায়ী data দেখানো
Relations	include	Related data আনা
Field Selection	select	নির্দিষ্ট fields আনা
Counting	count()	মোট record গণনা
Cursor Pagination	cursor	Cursor দিয়ে pagination



2. Important Code Examples
Filtering
const issues = await prisma.issue.findMany({
  where: {
    status: "open",
  },
});



Sorting:

const issues = await prisma.issue.findMany({
  orderBy: {
    createdAt: "desc",
  },
});

Pagination: 
const page = 1;
const limit = 10;

const issues = await prisma.issue.findMany({
  skip: (page - 1) * limit,
  take: limit,
});



Relations:

const issues = await prisma.issue.findMany({
  include: {
    reporter: true,
  },
});



Select Specific Fields:

const users = await prisma.user.findMany({
  select: {
    id: true,
    name: true,
    email: true,
  },
});


Count Records: 

const totalIssues = await prisma.issue.count({
  where: {
    status: "open",
  },
});

4. select vs include
- select → শুধু প্রয়োজনীয় fields নিয়ে আসে।
- include → মূল record-এর সঙ্গে related data নিয়ে আসে।
- একই query level-এ select এবং include একসঙ্গে ব্যবহার করা যায় না।






5. Real-World Application
Issue Forge project-এ:
- Search → where
- Filter by status → where
- Latest issues first → orderBy
- Page navigation → skip + take
- Reporter information → include
- Total issues → count()




6. মনে রাখার বিষয়
1. findMany() একাধিক records খুঁজে বের করে।
2. where দিয়ে filtering করা হয়।
3. orderBy দিয়ে sorting করা হয়।
4. skip এবং take দিয়ে pagination তৈরি হয়।
5. include দিয়ে relational data পাওয়া যায়।
6. select দিয়ে নির্দিষ্ট fields নির্বাচন করা হয়।
